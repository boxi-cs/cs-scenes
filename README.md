# cs-scenes

Reproducible computer science explanation scenes and lesson fixtures for the Boxi CS ecosystem.

> **Status:** scaffold. The first content packs are being designed against `cs-explain`.

Each scene should contain a runnable source example, fixed inputs or a seed, a canonical trace, assertions or invariants, a prediction checkpoint, a verification command, rendered fallbacks, and an accessibility transcript.

## Initial content packs

- `agent-loop-context`
- `evaluator-budget-score`
- `incident-retry-idempotency`

This repository consumes a fixed release of `boxi-cs/cs-explain`. It does not contain hidden assessment answers or private course data.

## Content contract

A scene is a teaching artifact, not only a recording. Its narrative must connect observation, prediction, execution, comparison, repair, and verification. Generated media is disposable; source, trace, assertions, and transcript remain reviewable.
