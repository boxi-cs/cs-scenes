# What does an agent actually see?

The controller receives one bounded question. It selects two relevant files and records the test file as omitted evidence. The agent requests one read within that boundary. The tool returns an observation about a cache-age check.

Pause here: is the dashboard fixed? No. The observation suggests a cause, but the episode still needs a regression test. A tool result is evidence to inspect, not proof that a change is correct.

The learner should compare this trace with an over-broad context: more text can hide the boundary and make it harder to say which evidence supported the action.
