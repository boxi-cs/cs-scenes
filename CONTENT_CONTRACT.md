# Content contract

Every lesson bundle records:

- learning objective and intended audience;
- source code and exact inputs or seed;
- canonical trace and schema version;
- prediction points and expected observations;
- assertions, tests, counterexamples, or other verification evidence;
- static rendering and accessible transcript;
- source and content license information.

A lesson must be runnable offline and reproducible from a clean checkout. A rendered video alone is not a sufficient source artifact.
